# Phase 02.1 Plan 16: Themes x Loadings Summary

**Tema (boot + system background) and carregamento (boot animation) are now two independent persisted choices: 4 themes from sketch 010, 4 loadings, a swappable boot-background step, and two config pickers with thumbnails, previa and aplicar.**

## Performance

- **Completed:** 2026-10-19
- **Tasks:** 5 (4 committed, Task 5 was the visual checkpoint, answered "aprovado")
- **Files:** 44 changed across the 4 task commits

## Accomplishments

- **Task 1 (tracer, `af68ffd`):** settings `theme_id`/`boot_style` independent and validated per field (T-02.1-39/40), `save_io` extracted from `game_state`, logo with alpha (rule of sketch 009, checked against its PNG), `ratimos_theme_t` catalog, splash on a 96-unit model with 5 fixed children, text shadow, ~400 ms fade, one `pronto!`, bandeira with seamless mast.
- **Task 2 (`d7747fa`):** ameias, letreiro and torres plus the deterministic generator for their sprites and 40x60 thumbnails; dirty/wave areas per style.
- **Task 3 (`b010de8`):** Noite, Castelo and Xadrez; static home backgrounds; home rebuilt when the theme generation changes; `theme.c` uses the displayed theme's `system_bg` (recolor for the 20% Castelo dim).
- **Task 4 (`2d5a9b9`):** "tema" and "carregamento" rows with pixel arrow, pickers, `cfg_tema`/`cfg_carregamento` icons, brand "RatimOS", provenance rows.
- **Task 5:** user approved the visual check against sketch 010.

## Format and measurements

- **Sprites/logo with alpha:** RGB565A8 (RGB565 plane + A8 plane); the opaque logo desc shares the first plane of the same buffer.
- **Flash for new art:** `boot_art.c` 162,840 B (wordmark glow 63,360; wall lit/unlit 12,804 each; 12 rook sprites 3,360 each; flag 1,392; 4 thumbs 7,200 each). `theme_art.c` 1,269,977 B (4 backgrounds 307,200 each; 8 thumbs 4,800 each; moon 2,187; tables 590). Logo with alpha 131,328 B (+43,776 over the old logo). 2 new icons about 0.8 KB.
- **LVGL heap, 3 laps (lap 2 / lap 3):** loadings 9,384 / 9,384 B; themes 9,384 / 9,392 B; picker previews (8 flows per lap) 38,800 / 38,688 B. No leftover `lv_timer`; touch input on after every flow.
- **Chess frame on PC:** 0.27 ms (-O2) / 0.39 ms (-O0) per row-render tick (339 rows), excluding the LVGL blit. ESP32 cost not measured.

## Deviations from Plan

**1. [Rule 1 - spec conflict] Letreiro follows the 010/011 canvas.** The plan prose said lit part = cols 34..edge, rows 95..136; the approved canvas lights the whole logo column from the left with a full-height glow stripe. Glow sprite is 192x110 (rows with content), with `RATIMOS_BOOT_GLOW_Y0` exported. Commit `d7747fa`.

**2. [Rule 3 - blocker] `-lm` added to `platformio.ini`.** Chess board needs `floorf`/`lrintf`; link failed without it. Commit `b010de8`.

**3. [Rule 1 - bug] A new splash deleting an older one no longer zeroes the new one's pointers** (found by a test); same guard in the picker. Commits `d7747fa`, `2d5a9b9`.

**4. [Rule 1 - bug] Implicit declarations of `lv_area_intersect` and `lv_image_cache_drop` fixed** with LVGL private-header includes (worked only by luck before). Commits `d7747fa`, `b010de8`.

**5. Design choices.** Background drawn at the last tick instant (`s_bg_now_ms`); toast at y=344 instead of ~360 (360 covered the buttons); `read_exact` also moved to `save_io.c`; test seam `ratimos_splash_set_fade_ms_for_test()`; `RATIMOS_DUMP_DIR` frame dumps in the UI suites.

**Total deviations:** 4 auto-fixed (2 Rule 1, 1 Rule 3, 1 spec reconciliation) plus design notes. **Impact:** none on the delivered behavior; letreiro matches what the user approved.
