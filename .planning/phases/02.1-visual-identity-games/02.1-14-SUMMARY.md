# Phase 02.1 Plan 14: Sketch 003-C type, background, rows and icons Summary

**The UI now uses JetBrains Mono for body text and Press Start 2P 8px for titles. The sketch 001-C background is drawn 1:1 and is pixel-identical to the sketch. The boot splash is black, list rows are a compact 48px with real 26px icons and game descriptions, and the hint is gone. During the checkpoint the user asked for 11 more fixes (modal dialogs, game layouts that fit without scrolling, the termo keyboard and locked letters, 'voltar' going to the right place, the splash bar, one card rhythm) and then approved the result.**

## Accomplishments
- **Fonts.** `ratimos_font_mono_10/11/12` (JetBrains Mono v2.304) and `ratimos_font_title_8` (Press Start 2P) cover ASCII, the PT-BR accents and `·`. `LV_FONT_DEFAULT` is now `ratimos_font_mono_12`. The mono fonts fall back to Montserrat 14, so `LV_SYMBOL_*` still renders. `convert_title_font.sh` now takes the TTF, prefix, sizes and `--fallback` as arguments, and the old one-argument usage still works.
- **Chrome.** The topbar shows "RATIMOS" in mono 10 with TEXT color, and the clock is mono 10. The breadcrumb is mono 11 in a single color, which closes deferred-items #4. A NULL hint creates no label, so "toque para abrir" no longer appears anywhere.
- **Background.** `generate_bg_dither.py` now runs the sketch algorithm: 10-level Bayer at 80x120, NEAREST scaling to 320x480, then 1px scanlines. `--check` confirms the output is pixel-identical to `bg-dither-scan.png`. The image is a 320x480 RGB565 const with no stretch. The LVGL heap did not grow: `lv_mem_monitor` on home went from 21672 to 21600 bytes.
- **Splash.** It no longer applies the gradient; the background is opaque black.
- **Rows.** The `text_col` height is now set by its content, which removes the ~150px rows from deferred-items #2. Rows have pad 9, gap 10, a 26px icon with a 2px pixel shadow drawn in DRAW_MAIN_BEGIN, a title_8 title and a mono_10 description, both single-line. The jogos list shows each game's description.
- **Icons.** Eight procedural 26x26 icons replace the raw `!`/B/V/F/S/L/P/T letters (closes deferred-items #3). The game icons are now rasterized at 26px.

## Decisions Made
See `key-decisions` in the frontmatter. The two that matter most for later plans:
- The fallback font is set on the generated mono descriptors, not on each label. So any new label that uses `LV_SYMBOL_*` works with the default font.
- Layout budgets are now named constants in `theme.h`, and `test_game_screens` enforces that every game fits. Future screen changes have to stay within `RATIMOS_CONTENT_INNER_H`.

## Issues Encountered
- **LVGL heap leak (deferred-items #1).** Every screen is cached forever. Five cached game screens use about 445KB of the 512KB pool, so `test_game_screens` adds a test-only LVGL pool. The real fix (delete-on-navigate) is scoped to plan 02.1-15.
- `test_sync_integration` needs `ADMIN_REGISTRATION_SECRET` / `TEST_DEVICE_TOKEN`. This environmental failure predates this plan.
