<objective>
Split the existing Phase-0 SDL2/LVGL shell into a board/HAL layer and a synchronous Storage/Content API, then wire the simplest possible end-to-end path through both: boot shows a real RatimOS splash (logo fade-in + genuine staged-progress bar) before landing on home, and the "cartas" app renders its list exclusively from fixture-backed data read through the new Storage API — proving the whole architecture (board split, storage separation, splash-driven staged init) holds before the remaining 4 apps and domains are expanded onto it in later plans.

Purpose: This is the phase's foundational tracer. Board/HAL separation (D-05/D-06/D-08) and the "storage API instead of hardcoded app content" pattern (D-09/D-10/D-11) are the two architectural risks RESEARCH.md flags as most consequential to get wrong — proving them on one thin, real path (letters -> cartas) before touching the other 4 apps means any structural mistake surfaces after one vertical slice, not after five.
Output: `src/board/*`, `src/storage/content_api.h` + `storage.c` + `letters.c`, `src/ratimos/splash.c/.h` + `logo_image.c/.h`, `cartas_app.c` wired, `assets/mock/letters/*`, `test/test_storage/test_storage.c` (Wave 0 scaffold).
</objective>
