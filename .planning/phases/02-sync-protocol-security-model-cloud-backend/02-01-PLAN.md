## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| PC-native C client (test/test_sync_integration/) → Supabase Edge Functions over HTTPS | Untrusted network path; the admin secret (register-device) crosses here in this plan, device bearer tokens cross here starting in Plan 2 |
| Operator (developer, via .env-sourced value) → register-device | Privileged path, gated by X-Admin-Secret (D-07) |
| register-device Edge Function → Postgres (service-role client) | Trusted internal path, bypasses RLS by design (D-09) |
| Any direct client holding only the publishable key → Postgres via PostgREST | Untrusted; must be denied by RLS default-deny (verified live in Plan 4) |
