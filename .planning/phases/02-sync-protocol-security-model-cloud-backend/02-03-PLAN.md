| T-2-03 | Tampering / Information Disclosure | base_url construction in ratimos_sync_whats_new | medium | mitigate | `base_url` is always the caller-supplied Supabase project URL, which is always the secure-scheme literal in this project's usage (Plans 1/4); this file never hardcodes or falls back to an unencrypted alternative. |
| T-2-08 | Tampering / Denial of Service | cJSON parsing of the whats-new response body | high | mitigate | `cJSON_Parse`'s return value is always NULL-checked before any field access; `strncpy` with explicit null-termination is used for every string field copy into the fixed-size struct, never a raw `strcpy`; `cJSON_Delete` runs on every return path. |
